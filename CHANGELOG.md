# Changelog

All notable changes to surveymap. Dates are the day the work landed locally.

## 0.1.0 — 2026-08-23

First release: journal-first survey flow mapping. `surveymap` scans the data
in memory, writes the journal, and prints the receipt; `draw` renders the
HTML flow map or mermaid text; `export` writes the Excel tracker, alone or
into a datadictionary workbook; `demo` shows the whole loop on fake data.
